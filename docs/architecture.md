# 系统架构

电脑开发模式下，浏览器访问 Vite `127.0.0.1:5173`，`/api` 代理到 FastAPI `127.0.0.1:8000`。手机演示模式下，Safari 访问 Cloudflare 临时 HTTPS 地址，经本机 Caddy `127.0.0.1:8080` 提供静态网页和 `/api` 反向代理。

FastAPI 连接本地 SQLite，将用户视频保存在 `uploads/`，视频分析请求转发到 RTMPose `127.0.0.1:8101`。实时摄像头骨架在浏览器中由 MediaPipe 处理，上传视频由 RTMPose 处理。

## 业务闭环

注册和首次测评 → 生成初始训练处方 → 开始训练 → 实时摄像头或视频分析 → 结束训练 → 归档报告和个人知识库 → 历史回看。未完成训练可以恢复或取消。

处方可提交给指定审核人。审核过程保存资料快照与意见；具体操作见 [处方审核](prescription_review.md)。

## 数据和边界

个人账号、测评、处方、训练与报告存放于本地 SQLite。上传视频按账号与训练编号分目录保存，媒体接口校验登录和用户归属。公网演示禁用固定弱口令演示账号，并通过 HTTPS 安全 Cookie 与来源校验保护写入请求。

部分 AI 服务仍为实验桩或备用结果，不能把占位分析解释为真实模型效果。正式多用户运行需要评估数据库、视频存储、备份、监控和推理资源。
